# Integrate approved assets

Read the asset issue and any accepted capability check for the exact provider mode/importer. Verify requested controls and actual output metadata; support by a provider name alone is insufficient. Stop on missing dimensions/facings/anchor or incompatible source identity.

Validate source/output names, transparency, frame counts and timing, pivots, references, stable IDs, and provenance. Use small authorized generation batches only through verified tools. Preserve approved source art and `.meta` identity. Never silently substitute a model/provider or broaden spending.

Run available structural/import checks and capture a representative in-game action where possible. Confirm animation timing does not own gameplay transactions. Report actual generation/import evidence and costs, including unknown costs as unknown. Contact sheets and successful imports are not human visual/play acceptance.
